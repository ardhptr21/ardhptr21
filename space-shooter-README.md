# Space Shooter Game - Member Profile

A cyberpunk-themed space shooter game with an interactive member profile dialog.

## Features

- **Cyberpunk Theme**: Dark background with cyan glowing effects
- **Member Profile Dialog**: Interactive modal displaying member information
- **Social Media Integration**: Links to Instagram, GitHub, and LinkedIn
- **Responsive Design**: Works on desktop and mobile devices
- **Interactive Elements**: Spaceship controls and laser effects

## Technologies Used

- HTML5
- CSS3 (with custom animations and cyberpunk styling)
- JavaScript (ES6+ classes and modern features)

## How to Run

1. Open `index.html` in a web browser
2. Or serve locally using Python: `python3 -m http.server 8000`
3. Click "MEMBER PROFILE" to view the member dialog
4. Use arrow keys to move the spaceship
5. Press space bar to shoot lasers
